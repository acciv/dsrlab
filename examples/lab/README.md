# Сценарии лаборатории

Сценарии определить в `examples/bundle.json` в массиве `scenarios`. Каждый сценарий
выполняется только на локальном `dsmock` (`127.0.0.1`). Примеры конечных точек:

- `/api/v10/rate-limited` — 429 и заголовок `Retry-After`;
- `/api/v10/forbidden` — 403;
- `/api/v10/users/@me` — 200 и синтетический профиль;
- `/api/v10/oauth2/token` — 200 и синтетический ответ (POST);
- `/api/v10/webhooks/100000000000000004/DUMMYWEBHOOK` — 204 (POST).

Настоящие токены и внешние адреса здесь не используются.
